# Danubius Studio

Dvojezični sajt za edukacijsko savetovanje, web development, razvoj igara i 3D štampu. Portfolio sadrži četiri javna projekta sa naloga `petroviner-web`, sa opisima zasnovanim na javnoj dokumentaciji. Podaci i prevodi su u `src/site-data.js`, a stranice u `src/App.jsx`.

Potreban je Node.js 22.12 ili noviji. Pokretanje: `npm ci`, zatim `npm run dev`. Produkcijski build: `npm run build`; provera: `npm test`; pregled: `npm run preview`. Generiše se 28 stranica. Statički sajt je u `dist/`. Podesiti `SITE_URL` za canonical linkove i mapu sajta. Netlify konfiguracija je u `netlify.toml`.

Trenutno nisu dostupni kontakt podaci ili stvarni tim, pa nema kontakt forme niti izmišljenih podataka. Edukacijsko savetovanje obuhvata istraživanje i podršku pri pisanju sopstvenog rada studenta. GitHub i Netlify povezivanje i provera produkcijske objave još nisu obavljeni.
