# Provera

Automatska provera obuhvata srpske i engleske stranice, veze, oznake jezika, četiri javna projekta i odsustvo kontakt forme. Prethodni koncept je proveravan u pregledaču, ali je nakon promene sadržaja i strukture potrebna ponovna vizuelna provera. Produkcijsko hostovanje i domen još nisu potvrđeni.
