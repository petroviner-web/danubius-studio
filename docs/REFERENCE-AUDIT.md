# Referenca i prilagođavanje

Javno dostupni Underpond sajt poslužio je kao inspiracija za velike tipografske kompozicije, skrol animacije, interaktivni uvod i vizuelni ritam. Danubius koristi sopstvenu grafiku, tekst i kod. Nisu kopirani klijenti, fotografije, video ili izjave reference. Nije reč o identičnoj reprodukciji svih efekata.

Nakon korisnikovih odgovora izmišljeni primeri portfolija su uklonjeni. Prikazani su GameOpen, DriveDiagnostics, PiControl i Thermal Camera na osnovu njihovih javnih GitHub README datoteka. Ograničenja navedenih projekata zadržana su u opisima.
